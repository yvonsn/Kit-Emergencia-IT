# Introducción

## Descripción del proyecto

**Kit de Emergencia IT** es un proyecto personal orientado a la creación de un dispositivo USB preparado para realizar tareas habituales de soporte técnico, diagnóstico, mantenimiento y recuperación de equipos.

El objetivo es disponer en un único dispositivo de diferentes entornos de arranque, herramientas portátiles, documentación técnica, drivers y scripts que puedan utilizarse durante una intervención de soporte.

---

## Objetivo

El proyecto busca centralizar y organizar recursos utilizados en tareas de soporte IT para facilitar su acceso y reducir el tiempo necesario para localizar las herramientas adecuadas.

El kit está preparado para realizar tareas relacionadas con:

- Diagnóstico de hardware.
- Análisis y mantenimiento de discos.
- Gestión de particiones.
- Clonado de discos.
- Copias de seguridad.
- Recuperación de datos.
- Diagnóstico de red.
- Mantenimiento de sistemas Windows.
- Análisis básico de seguridad.
- Acceso a sistemas mediante entornos Live.
- Instalación y actualización de drivers.
- Automatización de tareas básicas mediante scripts.

---

## Diseño del Kit

El dispositivo se ha preparado como un **USB multiboot mediante Ventoy**, permitiendo arrancar diferentes imágenes ISO desde un único dispositivo.

Además de los entornos de arranque, el USB contiene una estructura organizada de herramientas para soporte técnico.

Las principales secciones son:

- **ISO:** entornos de arranque y recuperación.
- **Aplicaciones:** diagnóstico, discos y recuperación.
- **Sistema:** herramientas para mantenimiento de Windows.
- **Red:** diagnóstico, escaneo y análisis.
- **Seguridad:** herramientas de análisis y protección.
- **Sysinternals:** utilidades avanzadas de administración de Windows.
- **Utilidades:** herramientas auxiliares.
- **Documentación:** procedimientos y referencias técnicas.
- **Drivers:** herramientas para gestión de controladores.
- **Scripts:** automatización de tareas frecuentes de soporte.

---

## Interfaz de acceso

Para facilitar la utilización del kit se creó una interfaz local mediante un archivo `index.html`.

Esta interfaz funciona como menú principal y proporciona acceso visual a las principales áreas del USB:

**Aplicaciones · Documentación · Drivers · Scripts · ISO**

De esta forma, las herramientas pueden localizarse de manera más rápida y ordenada durante una intervención técnica.

---

## Alcance

Este proyecto está diseñado como un entorno de aprendizaje y como herramienta personal de soporte técnico.

Las utilidades de administración, recuperación y diagnóstico deben utilizarse únicamente sobre equipos propios o sistemas para los que se disponga de autorización.
